# 占いリピート構造 + NG事例分析 リサーチレポート

調査日: 2026-03-27
モード: market（市場構造分析 + サービス比較 + NG事例）

---

## Executive Summary

**結論: AI占いでリピートを生むには「依存」ではなく「自己発見の余韻」を設計せよ。**

1. リピーターが生まれる核心は「言い当てられた感動」ではなく「自分を理解してもらえた安心感」+ 「次に確認したくなる余韻」の2段構造
2. AI占いの先行事例は「浅い・画一的・感情がない」で離脱するパターンが圧倒的に多い。成功例（Co-Star/DeepSeek占い）は「パーソナライズ」と「文化的文脈」で差別化
3. NG事例の本質は「不安の増幅」「判断の外部化」「経済的搾取」の3パターン。AI占いは「依存の低コスト化」という新たなリスクを持つ
4. 健全なモデルは「コーチング型」: 占いを鏡として使い、最終判断は必ず本人に返す設計

## 1. リピート構造のフレームワーク

### リピートが生まれる4段階モデル

```
[1回目: 衝撃と共感]
  「この人（AI）、私のことわかってる...」
  ├── バーナム効果: 誰にでも当てはまる記述を「自分だけ」と感じる
  ├── コールドリーディング: 観察+推論で「言い当て」を演出
  └── 傾聴の力: 「話を聞いてもらえた」という体験価値
          ↓
[2回目以降: 確認と安心]
  「あの時言われたこと、当たってた。次も聞きたい」
  ├── ザイオンス効果: 接触回数が増えるほど好感度UP
  ├── 認知的一貫性: 一度信じた占い師を信じ続けたい心理
  └── 確証バイアス: 当たった記憶だけが残る
          ↓
[継続: 関係性の深化]
  「この人は私の歴史を知っている」
  ├── 蓄積された文脈: 過去の相談内容を覚えている安心感
  ├── 成長の実感: 「前回と比べて変わった」というフィードバック
  └── 季節・周期: 「年の変わり目」「誕生日」などの自然なタイミング
          ↓
[理想のゴール: 自立]     vs    [依存の罠: 判断停止]
  占いを「確認」として使う        占いなしでは動けない
  最終判断は自分でする            「占い師に聞かないと不安」
```

### 対面 vs チャット vs AI占い の比較

| 項目               | 対面占い                       | チャット/電話占い                      | AI占い                         |
| ------------------ | ------------------------------ | -------------------------------------- | ------------------------------ |
| **リピート率**     | 高（関係性+場の力）            | 中〜高（手軽さ+依存リスク）            | 低（現状。個別化不足）         |
| **1回あたり単価**  | 3,000〜30,000円                | 1分200〜500円（30分で6,000〜15,000円） | 無料〜月額1,000円程度          |
| **依存リスク**     | 中（物理的障壁あり）           | 高（24h・匿名・低障壁）                | 中〜高（コスト障壁なし）       |
| **パーソナライズ** | 高（表情・声・雰囲気を読む）   | 中（テキスト/声のみ）                  | 低〜中（データ依存）           |
| **満足度の源泉**   | 「体験」全体（場・人・雰囲気） | 「共感」と「即時性」                   | 「手軽さ」と「気兼ねなさ」     |
| **強み**           | 五感を使った臨場感             | 深夜でも相談可能                       | 恥ずかしくない・待ち時間ゼロ   |
| **弱み**           | 時間・場所の制約               | 課金が青天井になりやすい               | 「冷たい」「浅い」と感じやすい |

### 「占い依存」にならない健全なリピートモデル

**コーチング型占いモデル（推奨）:**

- 占いは「問い」を立てるツール。答えは本人の中にある、という前提
- 毎回「あなたはどう思う？」で終わる設計
- 具体的な行動指針は出すが、「こうしなさい」とは言わない
- フォローアップは「その後どうでしたか？」ではなく「あの時の気づき、今も活きてますか？」
- 頻度の上限を設ける（週1回以上は「少し間を置きましょう」と促す）

### 成功しているサービスの共通点

1. **強烈なパーソナライズ**: 出生時刻・場所まで使い「あなただけの」結果を生成（Co-Star）
2. **文化的文脈との接続**: 伝統占術（四柱推命/西洋占星術）の権威を借りつつAIで拡張
3. **トーンの独自性**: Co-Starの「辛辣だが的確」、DeepSeekの「AIに占ってもらう面白さ」
4. **低障壁**: 無料 or 低価格で始められる。課金は深い分析やプロ相談に限定
5. **SNSシェアリング**: Co-Starの友人比較機能。DeepSeekのWeChat投稿文化

### 失敗しているサービスの共通点

1. **内容が浅い・画一的**: 「毎回似たような回答」「具体性がない」（AI占いくんの批判）
2. **感情の不在**: 「感情がこもっていない」「冷たい」と感じさせる
3. **占術への無理解**: ChatGPTの汎用応答を占いと称するだけ（精度が低いと現役占い師が指摘）
4. **フォローアップの欠如**: 1回きりで終わり、次に来る理由がない
5. **差別化の不足**: 「ChatGPTに聞けばいいじゃん」で代替される

## 3. 「また来たい」を生む対話設計

### 余韻を残す5つの手法

| 手法               | 説明                                     | 実装例                                                                   |
| ------------------ | ---------------------------------------- | ------------------------------------------------------------------------ |
| **未完の予言**     | 全てを語らず「この先に続きがある」と示唆 | 「3ヶ月後、ある出会いが...それは次回お話ししましょう」                   |
| **種まきの言葉**   | 日常で思い出すキーワードを残す           | 「"青い鳥"を見かけたら、今日の言葉を思い出して」                         |
| **自問の投げかけ** | 答えを持ち帰らせる                       | 「あなたが本当に恐れているのは、失敗ではないかもしれません。考えてみて」 |
| **時間軸の設定**   | 次回の自然なタイミングを作る             | 「次の新月（○月○日）に、今日決めたことを振り返ってみて」                 |
| **成長の予告**     | 未来の変化を示唆する                     | 「今の選択が実を結ぶのは○月頃。その時また話しましょう」                  |

### 個別化（パーソナライゼーション）の3層

```
Layer 1: データ個別化（最低ライン）
  生年月日・星座・血液型 → 基本的なプロフィル生成
  ↓
Layer 2: 文脈個別化（差別化ポイント）
  過去の相談履歴・選択肢の傾向 → 「前回○○で悩んでいましたね」
  ↓
Layer 3: 感情個別化（最高到達点）
  言葉遣い・応答速度・悩みの深さ → トーンと深度を動的に調整
  「あなたはいつも他人のことを先に考えるタイプ。でも今日は自分のことを話しにきた」
```

### フォローアップ設計

| タイミング      | 内容                                        | 目的                   |
| --------------- | ------------------------------------------- | ---------------------- |
| 鑑定直後        | 「今日のキーワード」をカード画像で送付      | 記憶の定着+SNSシェア   |
| 3日後           | 「○○について、少し考えてみましたか？」      | 余韻の維持             |
| 新月/満月       | 「今月の星の動き」+前回の文脈を踏まえた一言 | 自然なリピート導線     |
| 誕生月          | パーソナルな年間リーディング                | 特別感+年1回の定点観測 |
| 相談から1ヶ月後 | 「あの時の決断、どうなりましたか？」        | 成長実感+関係性深化    |

### 1回完結 vs 継続対話

|                | 1回完結型                                               | 継続対話型               |
| -------------- | ------------------------------------------------------- | ------------------------ |
| **満足度**     | 初回は高い（新鮮さ）                                    | 回を重ねるほど高まる     |
| **リピート率** | 低い（次に来る理由がない）                              | 高い（文脈の蓄積が資産） |
| **依存リスク** | 低い                                                    | 設計次第で高くなる       |
| **推奨**       | エンタメ層向け                                          | 本気で悩んでいる層向け   |
| **最適解**     | **ハイブリッド**: 1回で完結しつつ、次回への「種」を撒く |

## 4. NG事例の体系化

### NGパターン チェックリスト

#### A. 恐怖・不安の増幅（最も危険）

- [ ] **脅し系**: 「このままだと不幸になる」「災いが降りかかる」
- [ ] **霊感商法**: 「悪い霊がついている」「お祓いが必要」→ 高額商品の販売
- [ ] **不安の種まき**: 解決策を提示せず不安だけを残す
- [ ] **第三者遮断**: 「他の人に相談すると悪くなる」と孤立させる
- [ ] **期限設定**: 「今すぐ対処しないと手遅れになる」と急かす

#### B. 判断の外部化（依存の温床）

- [ ] **断定的指示**: 「○○しなさい」「○○してはいけない」と命令する
- [ ] **選択肢の排除**: 「これしかない」と1つの道を押し付ける
- [ ] **頻回利用の奨励**: 「毎日鑑定を受けるべき」
- [ ] **自己判断の否定**: 「あなたの判断は当てにならない」
- [ ] **上げ鑑定**: 良いことだけを言い続けて依存させる

#### C. 経済的搾取

- [ ] **課金の青天井**: 1分単位課金で止め時がわからない
- [ ] **追加商品の押し売り**: パワーストーン、お守り、祈祷料
- [ ] **段階的値上げ**: 信頼関係を築いてから高額プランに誘導
- [ ] **事例**: チャット占いで月80万円（週刊女性PRIME報道）
- [ ] **事例**: 占いサイト課金を繰り返し300万円（東京新聞報道）

#### D. 倫理違反

- [ ] **医療行為の代替**: 「病院に行かなくていい」「薬をやめろ」
- [ ] **法的助言**: 「離婚すべき」「訴えるべき」と専門外の指示
- [ ] **プライバシー侵害**: 相談内容の無断公開・悪用
- [ ] **差別的発言**: 「その星座は○○だから仕方ない」と決めつけ

#### E. AI占い固有のリスク（新規カテゴリ）

- [ ] **依存の低コスト化**: 無料・24h・匿名→歯止めが効かない
- [ ] **過信の誘発**: 「AIだから客観的」という錯覚
- [ ] **データプライバシー**: 悩みの内容が学習データに使われるリスク
- [ ] **感情操作のスケール**: 個別最適化された言葉でのマニピュレーション
- [ ] **誤情報の拡散**: 占術の知識が不正確なまま「それっぽく」出力
- [ ] **セラピーの代替誤認**: AIの共感的応答をカウンセリングと混同
- [ ] **判断力の外部委託**: 「AIが言ったから」で責任を放棄

### 占い依存の構造（心理メカニズム）

```
不安・悩み（トリガー）
  ↓
占いで「安心」を得る（一時的な報酬 → ドーパミン分泌）
  ↓
効果が切れる（不安の再燃）
  ↓
再び占いを求める（耐性の形成 → より頻繁に、より深く）
  ↓
自分で判断できなくなる（判断力の外部化）
  ↓
占いなしでは不安（依存の完成）
```

**依存に陥りやすい人の特徴:**

- 恋愛・人間関係で悩んでいる（利用目的の85%）
- 30〜50代女性（占い市場の顧客中心層）
- 「話を聞いてくれる心地良さ」にハマる（カウンセリング的機能への依存）
- 「納得できる結果が出るまで」繰り返す（占いジプシー）

## 5. So What -- アストレアへの推奨アクション

### 設計原則（Do / Don't）

| Do（やるべき）                                 | Don't（やってはいけない）              |
| ---------------------------------------------- | -------------------------------------- |
| 「あなたはどう思う？」で終わる                 | 「こうしなさい」と命令する             |
| 次の新月/季節の変わり目に「種」を撒く          | 「毎日鑑定を受けて」と頻回利用を促す   |
| 過去の相談文脈を蓄積して個別化する             | 毎回リセットされた汎用回答を返す       |
| 「前回と比べてこう変わった」と成長を示す       | 不安を煽って次回鑑定を促す             |
| 利用頻度が高すぎたら「間を置きましょう」と言う | 課金の上限を設けない                   |
| 「占いはヒント。決めるのはあなた」と明示する   | 「AIの分析だから正しい」と権威づけする |
| 深刻な悩みには専門家（医療・法律）を案内する   | 医療・法律の領域に踏み込む             |

### 差別化の方向性

1. **世界観の没入感**: Co-Starの「辛辣」やDeepSeekの「面白さ」ではなく、アストレアは「巫女との対話」という独自体験
2. **文脈の蓄積**: AI占いの最大の弱点「毎回リセット」を克服。過去の相談を踏まえた深い対話
3. **コーチング型終わり方**: 必ず「あなた自身はどう感じる？」で返す。判断を外部化させない
4. **自然なリピートタイミング**: 月の満ち欠け、季節の変わり目、誕生月など天体サイクルに連動
5. **安全装置**: 利用頻度の上限提案、深刻な相談への専門家リダイレクト、依存チェック機能

## 市場コンテキスト

- 日本の占いサービス市場規模: 約997億円（2023年度、矢野経済研究所）
- スピリチュアル関連市場全体: 約4.2兆円（2023年度）
- 顧客中心層: 30〜50代女性（90%）、利用目的の85%が恋愛・男女関係
- 成長市場: 対面・電話・チャット・スキルマッチング（オンラインサロン）が成長基調
- 世界の占星術アプリ市場: 2025年$153M → 2033年$372M（CAGR 11.3%）

## リスク・注意点

- **市場データの限界**: AI占い単体の市場規模データは存在しない。推定に依存 [未確認]
- **成功事例のバイアス**: Co-Starは米国市場。日本市場での再現性は検証が必要
- **DeepSeek現象の特殊性**: 中国の若年失業率・メンタルヘルス問題という特殊な社会背景が駆動力
- **倫理ガイドラインの不在**: AI占いに特化した業界ガイドラインは日本・海外ともに未整備
- **規制リスク**: 霊感商法等の被害防止法（消費者契約法改正2023）がAI占いにどう適用されるか未確定
