## エグゼクティブサマリ

**結論から3つ。**

1. **3枚引きのバリエーションは7つある**。うち本アプリに載せるべきは4〜5。相談内容で出し分ける方針は、実際のプロも「質問を1つに絞る」ことを精度の要件としているので理にかなっている
2. **コールドリーディングは「採用する技法」と「禁じる技法」を明確に分けるべき**。相手の言葉を拾う・開かれた質問をする、は正当。ストックスピール（誰にでも当たる曖昧文）は本アプリの「嘘をつかない占い」と正面衝突するので禁止側に置く
3. **AI占いの最大の危険は「感情的依存」**。研究者の結論は「技術は自己反省の代替ではなく、それを**強化する**ツールであるべき」。これは本アプリの「鏡」というスタンスと完全に一致するので、**明文化して守る**価値がある

**最大の発見**: プロのタロット読者が AI を使う理由は「解釈の楽をするため」だけでなく **「自分の偏見や仮定に異議を唱えるため」** だった。複数解釈を比較して、より響くものを選ぶ使い方。これは本アプリの RAG（過去の高スコア鑑定を参照）と同じ思想で、活かせる。

## 1. タロット実践 — 3枚引きの7バリエーション

[Luna Factory（プロ占い師監修）](https://tarot.lunafactory.co.jp/tarot-3-card-spread/) より。

| # | 呼び方 | 1枚目 | 2枚目 | 3枚目 | 向く相談 |
|---|---|---|---|---|---|
| ① | 時系列 | 過去 | 現在 | 未来 | 流れを掴みたい |
| ② | 問題解決 | 状況 | 障害・課題 | 解決のヒント | 具体的な行動に繋げたい |
| ③ | 関係性 | あなたの気持ち | 相手の気持ち | 二人の関係性 | 恋愛・人間関係 |
| ④ | 心身魂 | 心の状態 | 体の状態 | 魂のメッセージ | セルフケア |
| ⑤ | 一日の流れ | 朝 | 昼 | 夜 | その日の予測 |
| ⑥ | 二者択一 | 選択肢A | 選択肢B | どちらを選ぶべきか | 二択で迷っている |
| ⑦ | 期間指定 | 過去の影響 | 現在 | 1ヶ月後 | 期間を絞った予測 |

### リーディングの実務ノウハウ

- **質問を1つに絞る**ことが精度を上げる（最重要とされる）
- **3枚を「物語」として読む**。バラバラに解釈しない
- **中央のカードが核**で、左右が補完役
- **第一印象を信じる**。解釈にこだわりすぎない
- 正逆位置は**初心者は正位置のみでOK**。慣れたら逆位置で細かく読む
- 3枚引きは「基礎中の基礎」。10〜15分で深いリーディングができる**バランスの良さ**が人気の理由（[タロットパレット](https://sup.andyou.jp/tarot/threecard/)）

### 本アプリへの示唆

- **⑤一日の流れ / ⑦期間指定は外す**。対話型の鑑定には粒度が細かすぎる
- **①②③⑥ の4つ + ④** が候補。相談内容から3つ提示する方式に合う
- 「中央が核」という読み方は、**プロンプトに書ける実務知**。いま無い
- 「3枚を物語として読む」も同様。**バラバラに解説させない指示**として効く

## 2. コールドリーディング — 採用線と禁止線

[STUDY HACKER](https://studyhacker.net/cold-reading) / [日本占い師協会](https://www.uranai.org/horoscope/horoscope-column10/) より。

### 技法の実体（ストックスピール）

| 技法 | 中身 | 例 |
|---|---|---|
| あいまいルーズ | 複数の意味に取れる言い回し | 「非現実的な野望を抱いてしまう」 |
| 二重人格ルーズ | 正反対の性格を同時に提示 | 「外向的なときも、内向的で用心深いときもある」 |
| 不満ルーズ | 誰もが持つ不満を指摘 | 「現状に不満をもっていますね」 |
| おだてルーズ | 美点を褒める | 「自分に厳しすぎるところがある」 |
| ダブルバインドルーズ | YES/NO どちらでも当たる質問 | 「人の言うことを根拠なしに信じたりしない」 |
| 弱点ルーズ | 弱点を指摘してから褒める | 「弱点はあるが、たいてい埋め合わせている」 |
| 向上心ルーズ | 承認欲求を突く | 「人から好かれたい欲求が強い」 |

### なぜ効くか

- 「ほとんどの人は『心を言い当てられた』と**錯覚する**」
- 「**褒めてくれた人を信じやすい**傾向」
- 「『自分を理解してくれている』と感じた相手に**信頼感をもつ**」

### ⚠ 本アプリの方針と衝突する

現行 system prompt にはこう書いてある。

> - 操作しない。テクニックで「当てた」ように見せかけない
> - 二重構造・偽装（「本当の正体は〇〇」等）は禁止

**ストックスピールは定義上これに反する。** 「誰にでも当たる文を、その人だけに当てたように見せる」技法だからです。出典自身も「ニセ占い師や詐欺師も使っている技術」と明記しています。

### 切り分けの提案

| 採用する（コーチングと共通の正当技法） | 禁じる（欺きに属する） |
|---|---|
| 相手の言葉を拾って返す（リフレクション） | あいまいルーズ |
| 感情のラベリング | 二重人格ルーズ |
| 開かれた質問で引き出す | ダブルバインドルーズ |
| 沈黙を待つ | 弱点ルーズ・向上心ルーズ |
| 観察した事実を根拠として示す | 「当てた」演出全般 |

**根拠は本アプリが「実計算」を持っていること。** 星座もライフパスも実際に計算された事実です。曖昧な当て推量に頼る必要がそもそも無い。**ストックスピールを禁じても鑑定は成立します。**

## 3. AI占い — 既存動向と最大のリスク

[TechXplore（2026-05 / 研究記事）](https://techxplore.com/news/2026-05-tarot-readers-ai-reliance-chatbots.html) / [Jenova.ai](https://www.jenova.ai/en/resources/tarot-spread-ai) より。

### プロがAIを使う2つの理由

1. **解釈の負担軽減** — 複数カードを質問に照らして読む「フラストレーションの回避」
2. **自分の偏見に異議を唱えるため** — 複数解釈を比較し、より共鳴する読み方を探す

2つ目が重要です。**AI を「答えを出す装置」ではなく「視点を増やす装置」として使っている。**

### AI の構造的な弱点

> AI は通常「個人の経歴や状況のニュアンスについて**知識がない状態で**定義的な答え」を提供する

同じ「塔」のカードでも、相手の状況次第で意味が全く変わる。**対話で文脈を集めてから読む**設計でないと、AI 占いは薄くなります。本アプリが数往復の対話を挟む設計にしているのは、この弱点への正しい対処です。

### 最大のリスク: 感情的依存

> 生成AIユーザーの最大87%が「個人的応用」のため技術を相談している
> ユーザーは感情的依存を深め、**友人や家族の代わりにチャットボットに頼る**可能性がある

研究チームの結論:

> **技術は自己反省の代替手段ではなく、それを「強化する」ツールであるべき**

現行 system prompt の「毎日来て等の依存を促す言動」禁止は、この懸念に既に部分的に対応しています。ただし**弱い**。「依存を促さない」だけでなく「**自己反省を強化する**」を積極的な目標として書くべきです。

### 市場の動向

- 2025年に市場が分岐。AI アプリが生年月日と質問から**即時・大規模に**パーソナライズ鑑定を生成
- 先進的なプラットフォームは「感情的な状況を記述させ、**その状況に合わせたスプレッドを AI が設計**」する
- → **相談内容に応じてスプレッドを出し分ける方針は、業界の先端と同じ方向**

## 4. コーチング — 引き出す技法

[カオナビ](https://www.kaonavi.jp/dictionary/grow-model/) / [日本NLP能力開発協会](https://nlp-coaching.or.jp/grow-model/) より。

### GROW モデル

| 段階 | 内容 |
|---|---|
| **G**oal | 目標設定 |
| **R**eality | 現状把握 |
| **O**ptions | 選択肢の検討 |
| **W**ill | 意思決定 |

### 基盤スキル3つ

質問技法 / 傾聴（アクティブリスニング）/ フィードバック。
そして「パワフルクエスチョン」で対話の質を高める。

### 本質

> コーチングは「教える」のではなく「**引き出す**」。相手の**自発的な行動変容**を促す

### 本アプリへの示唆

現行の対話フロー（フェーズ1〜5）は GROW と構造が似ています。

| 本アプリ | GROW |
|---|---|
| フェーズ1-2 出迎え・カード | （ラポール形成） |
| フェーズ3 占術結果を鏡として提示 | Reality（現状把握） |
| フェーズ4 対話を通じた気づき | Reality → Options |
| フェーズ5 本鑑定「三つの星の道」 | Options → Will |

**「三つの星の道」が Options に相当し、Will（意思決定）が弱い。** 現行は具体アクション3つを提示して終わりですが、コーチングなら「**どれから始めますか**」と本人に選ばせて締めます。ここは改善余地。

## So What — 実装への落とし込み

### 提案1: スプレッド定義（5種）

相談内容に応じてアストレアが3つ提示し、相談者が1つ選ぶ。

| id | 名前 | 1枚目 | 2枚目 | 3枚目 | 出す条件 |
|---|---|---|---|---|---|
| `timeline` | 時の流れ | 過去 | 現在 | 未来 | 漠然とした不安、節目、流れを知りたい |
| `situation` | 現状と道 | 状況 | 障害 | 助言 | 具体的な悩み、行動に繋げたい |
| `relation` | 二人の間 | あなたの気持ち | 相手の気持ち | 関係の行方 | 人間関係・恋愛 |
| `choice` | 分かれ道 | 選択肢A | 選択肢B | 決め手 | 二択で迷っている |
| `mindbody` | 心と身体 | 心 | 身体 | 魂のメッセージ | 疲れ、不調、セルフケア |

**根拠**: プロ監修の7バリエーションから、対話型鑑定に合う5つを採用。①②③④⑥ に対応。⑤⑦（一日の流れ / 期間指定）は粒度が細かく対話に向かないため除外。

### 提案2: system prompt に足すべき実務知

いま入っていないもの。

1. **「3枚を物語として読む」** — バラバラに解説させない
2. **「中央（2枚目）が核、左右が補完」** — 読みの重心を与える
3. **選んだスプレッドの位置の意味を明示** — いま「1枚目/2枚目/3枚目」としか渡していない
4. **ストックスピール禁止の明文化** — 「誰にでも当てはまる曖昧な表現で当てたように見せない」
5. **Will の追加** — 本鑑定の締めで「どれから始めますか」と選ばせる

### 提案3: 依存対策を積極目標に

現行「依存を促す言動の禁止」を、研究の結論に合わせて書き換える。

> 占いは自己反省の**代替**ではなく、それを**強化する**ためのもの。
> 相談者が自分で考える余地を必ず残す。答えを与えきらない。

### 提案4: 画面表示（「めくる順を伝える」の答え）

スプレッドを選んだ時点で、位置の意味を画面に出す。

```
  ┌──────┐  ┌──────┐  ┌──────┐
  │  ?   │  │  ?   │  │  ?   │
  └──────┘  └──────┘  └──────┘
    過去      現在      未来
   1枚目に   2枚目に   3枚目に
   めくる    めくる    めくる
```

これで「めくった順に意味がある」ことが初めて伝わります。
