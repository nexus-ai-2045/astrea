# タロット図案の置き場

大アルカナ 22 枚の図案をここに置く。

## 命名規則

`<2桁ゼロ埋めのカード番号>.webp`

```
00.webp  愚者 The Fool
01.webp  魔術師 The Magician
...
17.webp  星 The Star
21.webp  世界 The World
```

番号は `src/lib/tarot.ts` の `MAJOR_ARCANA[].number` と一致させる。

## 有効化

置いただけでは表示されない。`src/lib/tarot-art.ts` の `AVAILABLE_TAROT_ART`
に番号を足して初めて使われる。未登録の札は現行の CSS デザインのまま表示される。

一覧を手で持っているのは、クライアント側で public/ を走査できないことと、
置いただけの未完成画像が勝手に出るのを防ぐため。

## 仕様

- アスペクト比 2:3（カード枠が 2:3 のため。ずれると object-fit: cover で切れる）
- 文字情報（番号・札名・キーワード・正逆）はアプリ側が上に重ねるので、
  **画像に文字を入れない**こと
- 22 枚の画風を揃える。混在すると 1 枚ずつ綺麗でもデッキに見えない
